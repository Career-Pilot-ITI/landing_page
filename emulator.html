Jetpack Compose Internals
The Recomposition Process and The Gap Buffer

In Jetpack Compose, the UI is a function of state. When state changes, the framework triggers recomposition. To do this efficiently, Compose uses a SlotTable—a specialized data structure based on a Gap Buffer—to store composition information.

Example: 
@Composable
fun UserProfile(user: User) {
  // Compiler tracks 'Text'
  Text(text = user.name)
  AgeDisplay(age = user.age)
}
